# n8n Setup & Usage Instructions

Refer to [README.md](./README.md) for full configuration details.

## Quick Summary

- **Start**: `docker compose up -d` (or `pnpm n8n:up`)
- **Stop**: `docker compose down` (or `pnpm n8n:down`)
- **Logs**: `docker compose logs -f` (or `pnpm n8n:logs`)
- **Web UI**: http://localhost:5678
- **Ollama Host URL**: http://host.docker.internal:11434
- **Server Host URL**: http://host.docker.internal:3001
