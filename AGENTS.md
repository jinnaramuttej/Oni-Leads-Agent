# Agent Directives & Workspace Rules

## Mandatory Actions

1. **Read `AGENTS.md` First**:
   - Always inspect and read `AGENTS.md` at the beginning of handling requests to ensure compliance with current project guidelines.

2. **Git Commit & Push Policy**:
   - Automatically stage (`git add`), commit, and push (`git push`) changes to the git repository after working on tasks or making distinct updates.
   - Perform commits and pushes multiple times within a single turn/response if multiple distinct features or milestones are completed.
   - **Commit Style**: Use short, clear, non-AI-ish commit messages written like an engineer (e.g., `add excel import script`, `fix supabase place_id constraint`, `update workspace scripts`), avoiding verbose or robotic templates.
